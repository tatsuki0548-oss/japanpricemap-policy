日本房價地圖 隱私權政策與使用條款

最後更新：2026年11月5日

本文件說明「日本房價地圖」（Instagram、Facebook 粉絲專頁、YouTube：@japanpricemap）的營運者，在回覆留言時使用的工具（以下稱「本工具」）如何處理資料。日文版在下方。

1. 營運者與聯絡方式

營運者：日本房價地圖
聯絡信箱：japanpricemap@gmail.com

營運者的姓名與地址，如有需要，請來信詢問，我們會儘速回覆。留言內容、資料刪除、安全問題的回報，也請寄到這個信箱。

2. 本工具做什麼

本工具在營運者自己的電腦上執行，只有營運者本人使用。它讀取我們的貼文收到的公開留言，用 AI 產生回覆的草稿，由營運者逐則確認，按下按鈕後才發布。沒有全自動回覆。AI 只提供草稿，內容也不是法律、稅務或投資方面的專業建議。

3. 處理哪些資料、從哪裡取得

  • 來源：透過 Instagram、Facebook、YouTube 的官方 API，取得我們的貼文和影片底下的公開留言。不取得被隱藏或待審核的留言。
  • 留言的內容、留言時間、留言 ID。
  • 留言者的使用者名稱或顯示名稱、帳號 ID（用來顯示和分辨是誰的留言）。
  • 我們的貼文資訊（標題、說明文字、連結、發布時間）。
  • 讀取和發布所需的存取權杖（只用於我們自己的帳號）。

4. 使用目的

只用於閱讀留言、產生回覆草稿、發布營運者確認過的回覆。我們不販售資料、不用於廣告、不建立個人檔案、不做情緒判定或評分、不用於訓練 AI。不同平台的資料不會合併或統計。

5. 委託處理（Anthropic）

為了產生草稿，我們會把留言的內容傳送給美國的 Anthropic, PBC（Claude API）。使用者名稱、帳號 ID、權杖不會傳送，留言中的 @ 標記也會先遮蔽。含有病歷等敏感資訊或聯絡方式的留言，原則上不會傳送。

依 Anthropic 的商業服務條款與資料處理附約，傳送的內容不會用於訓練模型。Anthropic 通常在30天內自動刪除，但判定違反使用政策時可能保留較長時間（最長2年，分類結果最長7年）。詳情請見 Anthropic 隱私權中心。

6. 處理的地區

日本（營運者的電腦）和美國（Anthropic，以及各平台的伺服器）。

7. 保存期間

資料只存在營運者的電腦裡，不會同步到雲端或備份。一段對話結束後就刪除。超過25天沒有新動態的對話會自動刪除，最長不超過30天；對話持續進行時，內容會隨時更新為平台上的最新狀態。留言者刪除留言後，我們保存的內容也會一併刪除。

8. 刪除資料與您的權利

任何人都可以請求查閱、複製、更正、停止處理或刪除自己的資料，不收費。請將留言的連結或使用者名稱寄到上述信箱。我們會在7天內刪除，並回覆處理結果。其他請求依相關法律（查閱類15天內、更正與刪除類30天內）回覆。

請注意：我們刪除的是本工具保存的資料。平台上公開的留言本身，請到該平台刪除。

9. 如何解除連結

  • YouTube／Google：Google 帳戶的第三方連結設定。
  • Instagram：應用程式的「設定」裡的網站權限。Facebook：「設定與隱私」裡的商業整合。
  • 營運者也可以在本工具內解除連結，權杖會立即刪除，保存的對話也會一併刪除。

10. YouTube API 服務

本工具使用 YouTube API 服務。使用本工具與 YouTube 互動時，適用 YouTube 服務條款，Google 如何處理資料請見 Google 隱私權政策。

11. Cookie、廣告與第三方內容

本頁面和本工具都不使用追蹤用的 Cookie，也沒有第三方廣告。本工具在營運者的電腦上保存資料庫和權杖檔案，不會在您的裝置上儲存任何東西。

12. 安全措施

資料和權杖保存在只有營運者本人能讀取的位置，不對外開放連線；傳輸時使用加密連線；只取得必要的權限；並留意委託處理地區（美國）的相關制度。

13. 使用條款

本工具只供營運者本人使用，不對外提供。使用本工具與 YouTube 互動，即表示同意遵守 YouTube 服務條款。本工具依各平台的條款運作，不保證持續提供。

14. 變更

本文件變更時，會更新本頁的日期。使用方式有重大變更時，會在變更前更新內容。
